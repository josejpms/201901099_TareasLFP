# Helado 3D

Escena interactiva de un helado modelado de forma procedural con **Three.js**.

## Cómo verlo

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
python3 -m http.server 8080 --bind 127.0.0.1 --directory helado-3d
```

Luego visita `http://127.0.0.1:8080`.

## Controles

- **Arrastrar** para orbitar la cámara
- **Scroll** para acercar o alejar
